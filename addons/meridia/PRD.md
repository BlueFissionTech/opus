# Meridia

Meridia helps users and governors identify a permitted route before choosing
whether to invoke it. This first source package resolves registered local routes
and explicit intent labels without classifying language or executing a target.

Acceptance for this increment: a real DevElation Mapping supplies the target;
Wise exposes list, validate, explain, resolve and dry-run; authenticated host
context controls discovery and resolution. Highest explicit priority wins, ties
abstain, aliases cannot cross scope or loop, and stale sources cannot resolve.
Discovery and resolution use the same immutable candidate snapshot. Host bindings
are explicit; installation does not register routes or grant capabilities.

Crawling is disabled, with a zero request budget. Live crawling, Annex manifest
verification, Synematic invocation workflows, route activation/mutation, shared
cache invalidation and service deployment remain separate acceptance gates.
No remote service or routes.bluefission.com deployment is claimed.
