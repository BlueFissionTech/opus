# AGENTS.md - Repository Instructions

Read `AGENTS.standards.md` before reviewing or modifying this repository.
Also read the local `AGENTS.behavior.md` when present.

- `AGENTS.standards.md` defines the mandatory DevElation coding and review
  standards.
- `AGENTS.behavior.md` is optional, untracked operating and coordination policy.
  Keep a local copy when updating from a revision that tracked this file.
- Neither companion document may weaken security, branch protection, or
  higher-priority operator instructions.
